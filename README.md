# Carpooling Platform

A Software Engineering course project focused on designing a web-based Carpooling Platform that connects drivers and passengers for efficient ride sharing. The project was developed following Agile Scrum practices and emphasizes requirement engineering, system modeling, documentation, and software testing.

## Project Overview

The Carpooling Platform aims to provide a convenient, cost-effective, and sustainable transportation solution by enabling users to share rides. The system allows drivers to offer rides and passengers to search, request, and book available trips through a centralized platform.

## Features

* User Registration and Authentication
* Driver and Passenger Profiles
* Ride Posting and Management
* Ride Search and Booking
* Ride Request Handling
* Payment Management
* Notifications and Updates
* Administrative Dashboard
* User and Ride Monitoring
